Conab atualiza portal de informações com dados corporativos e painéis gerenciais

A Companhia Nacional de Abastecimento lançou uma versão atualizada do Portal de Informações, reunindo dados corporativos e painéis gerenciais em um único ambiente.

A atualização do portal concentra os painéis gerenciais e as bases de dados corporativas, priorizando a localização, organização e visibilidade das informações para facilitar o acesso dos usuários.

Os dados privados são classificados em dois níveis de sensibilidade: o nível 1 é restrito ao uso interno, enquanto o nível 2 conta com mecanismos adicionais de segurança para proteção das informações.

Nesta primeira fase, o foco foi consolidar os ambientes de informação já existentes, além de aprimorar a interface, a usabilidade e a governança dos dados disponibilizados.

Para a segunda etapa, está prevista a oferta de Interfaces de Programação de Aplicações (APIs) que permitirão o acesso aos dados públicos, possibilitando a integração e padronização das informações em sistemas e outras soluções tecnológicas.

O portal atualizado já está disponível para acesso no endereço portaldeinformacoes.
